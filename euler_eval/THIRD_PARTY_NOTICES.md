# Third-party notices

`euler-eval` bundles the pristine natural-scene model parameters from the NIQE
software release and the foggy/fog-free model parameters from the FADE software
release. These assets and the corresponding metric implementations are based on
software published by the Laboratory for Image and Video Engineering (LIVE).
